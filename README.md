## About the Internship

This repository contains the internship report and presentation for the
10-week Machine Learning & Data Science internship completed through
EduSkills Academy.

The internship covered Machine Learning and Data Science fundamentals
along with practical software development projects focused on automated
web scraping and internal software tools.

The major areas covered included Python, NumPy, Pandas, data
visualization, Scikit-learn, NLP, SQL, Flask, Power BI, Selenium, MLOps
concepts, and AI-assisted development.

------------------------------------------------------------------------

## Projects

### 1. Google Maps Web Scraper

A web scraper was developed using **Python** and **Selenium** to extract
structured business listing information such as names, addresses,
ratings, and contact details from Google Maps.

The project was developed until server-side anti-scraping limitations
were encountered, after which it was escalated for further evaluation.

### 2. E-Commerce Web Scraping Framework

A generic and reusable web scraping framework was developed and adapted
for multiple e-commerce and quick-commerce platforms.

The framework focused on extracting structured information including:

-   Product names
-   Prices
-   Availability status
-   Location details

The framework was successfully extended to **10 out of 13 targeted
platforms**.

Completed platforms included:

-   Amazon
-   Flipkart
-   BigBasket
-   Zepto
-   Nykaa
-   Myntra
-   JioMart
-   Purplle
-   Tira
-   Smytten

### 3. Accompanying Data Presentation Website

A front-end website was developed to present the scraped multi-platform
data in a user-friendly interface.

The front-end development was completed, while deployment was pending
beyond the internship tenure.

### 4. HRMS Customization

An open-source Human Resource Management System (HRMS) was cloned from
GitHub with the intention of customizing and deploying it on a personal
server.

The project remained incomplete because the internship tenure concluded
with the resumption of college activities.
